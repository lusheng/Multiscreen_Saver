## 预览与资源边界

系统设置中的零尺寸 preview=true 视图与负责缩略画面的全尺寸 preview=false 渲染代理不是同一实例，后者可以按设置中选中的真实显示器渲染。此处不把 false 当作“用户正处于全屏屏保”的信号。诊断版本每视图独立持有图片、取消 ticket 和 CA 图层，没有共享播放队列；目前可见缩略画面仍显示诊断动画，这不是对 G1 预览资源约束的豁免。关闭设置时代理视图移出、动画及 timer 清零并销毁；后续真实全屏重新创建 H/V 实例，未继承预览状态。这些证据仅证明已观察到的生命周期清理与每视图状态隔离；设置页代理的持续动画/timer 仍需按 G1-05 的预览资源约束复核，所以该项保持 PENDING，不能直接放行未来完整播放器。

真实宿主的 start 可能重复；stop 也可能不先到达而直接移出窗口。两条清理路径均已在实际日志中覆盖。普通进程的零尺寸/未挂接检查为补充，未代替真实宿主观察。
