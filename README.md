# Multiscreen Saver

面向 **macOS 27 Golden Gate** 的原生照片屏幕保护程序规划：横屏与竖屏分别使用用户指定的本地图库，播放带缩放、平移和交叉淡入淡出的 Ken Burns 照片动画。

**当前状态：2026-10-18，build 16 的 G1 六项实机检查已全部通过，G2/G3 首个完整播放器已实现并通过自动检查，build 19 已通过首轮真实图库双屏观察，完整实机矩阵仍在执行；G4 稳定性未执行，产品尚未完成。** 采用 MIT 许可证。参见 [G1 实测记录](docs/validation/g1.md) 、[完整播放器开发步骤](docs/development.md) 和 [G4/G5 状态](docs/validation/g4-g5.md)。

## 需求

- 横屏（典型 16:9）和竖屏（典型 9:16）分别选择图库文件夹。
- 每张照片从填满屏幕的基准尺寸缓慢放大，默认终点随机为 1.10–1.20 倍，并伴随平移；全过程不露出图片外缘。
- 照片之间交叉淡入淡出；默认每张时长 5 秒，淡入淡出 1.5 秒，具体计时语义见规划。
- 随机播放一轮内不重复，结束后重新洗牌；也支持顺序播放。
- 支持 JPG/JPEG、PNG、HEIC、WebP，递归子目录可选。
- 原生配置界面：两处图库目录、时长、淡入淡出、缩放上限、播放顺序、递归开关。

## 安装与使用

当前提供源码构建安装，尚无正式二进制 Release。目标环境为 macOS 27 / Apple Silicon，编译需要已安装并可用的 Xcode；其他系统或设备的兼容性尚未验证。当前版本仍在开发测试，长时间稳定性及完整实机矩阵尚未验收完成，详见 [G4/G5 状态](docs/validation/g4-g5.md)。

### 1. 获取源码并编译

在终端执行：

```sh
git clone https://github.com/lusheng/Multiscreen_Saver.git
cd Multiscreen_Saver
./scripts/build.sh
```

如果已有本仓库，进入仓库目录后执行构建命令即可。默认构建 Release，产物为 `build/MultiscreenSaver.saver`。本项目使用原生框架，运行屏保无需安装 Python 或其他第三方依赖。

### 2. 安装到当前用户

先记下每块显示器原来的屏保选择，然后执行：

```sh
./scripts/install-local.sh
```

脚本会验证签名，并安装到 `~/Library/Screen Savers/MultiscreenSaver.saver`，无需 `sudo`。若已有同名安装，旧版本会备份到仓库的 `Private/` 目录。脚本只安装本项目，不会自动改变当前屏保选择。当前采用开发签名，尚未承诺其他机器的签名或公证兼容性。

### 3. 选择屏保并设置图库

1. 打开 **系统设置 → 墙纸 → 屏幕保护程序**，对每块显示器选择 **MultiscreenSaver**。
2. 点击 **“选项…”**，分别选择横屏和竖屏使用的本地图库文件夹并保存。屏保根据所在显示器的横竖方向选用对应图库。
3. 按需调整播放参数。默认照片切换间隔为 **5 秒**、交叉淡入淡出 **1.5 秒**、最大缩放 **1.20**，随机播放开启、递归子目录关闭。详细计时语义见 [开发规划](docs/plan.md)。

图库支持 JPG/JPEG、PNG、HEIC、WebP。若照片放在所选文件夹的子目录内，请开启递归扫描。空图库或目录访问失效时会显示提示，可重新打开选项选择有效目录。

### 更新与卸载

更新时，退出正在运行的屏保，获取所需版本的源码后重新执行构建和安装脚本；旧安装仍会备份到 `Private/`。

卸载时，先为每块显示器切换到其他屏保，再在 Finder 中使用 **前往 → 前往文件夹…** 打开 `~/Library/Screen Savers/`，将 `MultiscreenSaver.saver` 移到废纸篓。如需恢复旧版本，可使用仓库 `Private/` 中的对应备份。

## 隐私与许可

本项目面向本地图库，不计划联网获取照片或收集使用数据。照片、真实目录、文件访问书签和个人运行日志不进入仓库。
