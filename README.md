# Multiscreen Saver

面向 **macOS 27 Golden Gate** 的原生照片屏幕保护程序规划：横屏与竖屏分别使用用户指定的本地图库，播放带缩放、平移和交叉淡入淡出的 Ken Burns 照片动画。

**当前状态：调研与方案审阅阶段，尚未实现或发布屏保。** 用户批准方案后才编写 `goal_prompt.md`，供新的目标模式会话执行。

## 需求

- 横屏（典型 16:9）和竖屏（典型 9:16）分别选择图库文件夹。
- 每张照片从填满屏幕的基准尺寸缓慢放大，默认终点随机为 1.10–1.20 倍，并伴随平移；全过程不露出图片外缘。
- 照片之间交叉淡入淡出；默认每张时长 5 秒，淡入淡出 1.5 秒，具体计时语义见规划。
- 随机播放一轮内不重复，结束后重新洗牌；也支持顺序播放。
- 支持 JPG/JPEG、PNG、HEIC、WebP，递归子目录可选。
- 原生配置界面：两处图库目录、时长、淡入淡出、缩放上限、播放顺序、递归开关。

## 隐私与许可

本项目面向本地图库，不计划联网获取照片或收集使用数据。照片、真实目录、文件访问书签和个人运行日志不进入仓库。

仓库公开可见；项目许可证尚待所有者选择，目前未添加 `LICENSE`。调研中没有引入第三方产品源码或素材。
